# Recorder in Simple Client — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Simple Client records the Syphon source it displays to a movie file, driven from its window, by OSC (described by OSCQuery) and by MCP.

**Architecture:** A Syphon-free Objective-C core in `Recorder/` (frame pacing, Metal → AVAssetWriter, OSC, OSCQuery) compiled both into the app and as the SwiftPM target `RecorderKit`, so `swift test` covers it. `RecorderController` in the app holds one parameter table used by the window, OSC and OSCQuery. `simple-recorder-mcp` is a stdio Swift tool which reads through OSCQuery and writes through OSC.

**Tech Stack:** Objective-C (ARC), Metal, AVFoundation, CoreVideo, BSD sockets, NSNetService; Swift for tests and the MCP tool; Xcode 16 workspace + SwiftPM.

**Spec:** `docs/superpowers/specs/2026-10-01-recorder-design.md`

Adrien asked for the implementation to follow the design without a review stop, executed in this session. This plan therefore fixes interfaces, test cases and commands exactly, and leaves method bodies to the task.

## Review Focus

Inputs the spec implies and which are most likely to bite, each pinned by a test in the task which owns the code:

1. **The source changes size while recording** (Simple Server's window is resized): the file keeps its size, the frame is scaled to fit — Task 5, `testSourceSizeChangeKeepsOutputSize`.
2. **A malformed or hostile OSC packet** (truncated, wrong padding, unknown type tags): ignored, no crash, later packets still handled — Task 2, `testMalformedPacketsAreIgnored`.
3. **Odd or zero dimensions** (a 641 × 481 source, width set without height): even output size, never a writer error — Task 5, `testOddSourceSizeIsRoundedDown`, `testOneDimensionZeroUsesSourceSize`.
4. **The port is already taken** (9230 by another app, or a second instance): the next port is used and reported — Task 3, `testSecondReceiverTakesNextPort`.
5. **An unwritable or missing folder**: starting fails with a message, the state stays idle — Task 5, `testStartFailsForMissingFolder`; Task 6 routes it to `/status/error`.
6. **Two servers with the same title** (eMotion publishes two "main view"): `/source` selects the first, the menu can still select either — Task 6, checked end to end in Task 9.
7. **Quitting or closing the window while recording**: the file is finished first — Task 6, checked end to end in Task 9.

### Task 1: Package scaffold and FramePacer

**Files:** Create `Package.swift`, `Recorder/FramePacer.h`, `Recorder/FramePacer.m`, `Tests/RecorderKitTests/FramePacerTests.swift`. Modify `.gitignore` (add `.build/`).

**Interfaces — Produces:**

```objc
typedef struct {
    BOOL keep;
    double time;   // presentation time in seconds, 0 for the first frame
} FramePacerDecision;

@interface FramePacer : NSObject
// framesPerSecond 0 keeps every frame
- (instancetype)initWithFramesPerSecond:(double)framesPerSecond;
// time: when the frame arrived, in seconds from any origin. The first call defines time 0.
- (FramePacerDecision)decisionForFrameAtTime:(double)time;
@end
```

Rule: with a cap, slot = `round((time − first) × fps)`; a frame is kept when its slot is greater than the last kept slot, at time `slot / fps`. Rounding (not flooring) lets a source at the cap's own rate, with jitter under half a period, keep every frame. Without a cap a frame is kept at `time − first` when that is greater than the last kept time.

- [ ] **Step 1:** write `FramePacerTests.swift`:
  - `testFirstFrameIsKeptAtZero`
  - `testNoCapKeepsEveryFrameAtItsArrivalTime` — arrivals 10.0, 10.5, 10.7 → times 0, 0.5, 0.7
  - `testNoCapDiscardsFrameWhichDoesNotAdvance` — two frames at the same time → second discarded
  - `testSourceTwiceTheCapKeepsHalf` — 120 arrivals at 1/120 s, cap 60 → 60 kept, times k/60
  - `testSourceAtTheCapWithJitterKeepsAll` — 60 arrivals at k/60 ± 3 ms alternating, cap 60 → 60 kept, times k/60
  - `testSourceSlowerThanCapLeavesGaps` — arrivals at k/10 for 1 s, cap 60 → 10 kept, times 0, 0.1, … (multiples of 1/60 nearest)

### Task 5: MovieRecorder

**Files:** Create `Recorder/MovieRecorder.{h,m}`, `Tests/RecorderKitTests/MovieRecorderTests.swift`.

**Interfaces — Consumes** `FramePacer`. **Produces:**

```objc
typedef NS_ENUM(NSInteger, MovieCodec) {
    MovieCodecH264,
    MovieCodecHEVC,
    MovieCodecProRes422,
    MovieCodecProRes4444
};

extern NSString * const MovieRecorderErrorDomain;

@interface MovieRecorderSettings : NSObject <NSCopying>
@property (assign) MovieCodec codec;
@property (assign) NSInteger width;              // 0: the source's
@property (assign) NSInteger height;             // 0: the source's
@property (assign) double framesPerSecond;       // 0: every frame
@property (assign) double megabitsPerSecond;     // 0: automatic; ignored by ProRes
// "h264", "hevc", "prores422", "prores4444"
+ (NSArray<NSString *> *)codecNames;
+ (NSString *)nameForCodec:(MovieCodec)codec;
+ (BOOL)getCodec:(MovieCodec *)codec forName:(NSString *)name;
@end

@interface MovieRecorder : NSObject
- (instancetype)initWithDevice:(id<MTLDevice>)device;
// Fails if a recording is in progress or the file cannot be created. The file's size is decided by the first frame.
- (BOOL)startWritingToURL:(NSURL *)url settings:(MovieRecorderSettings *)settings error:(NSError **)error;
// Any thread; returns at once. flipped: the first row of the texture is the bottom of the picture.
// time: when the frame arrived, in seconds, on the clock also given to finishAtTime:
- (void)appendTexture:(id<MTLTexture>)texture flipped:(BOOL)flipped atTime:(NSTimeInterval)time;
// Waits for frames in flight, ends the movie at time, finishes the file. handler runs on the main queue.
- (void)finishAtTime:(NSTimeInterval)time completionHandler:(void (^)(NSError * _Nullable error))handler;
@property (readonly, getter=isRecording) BOOL recording;
@property (readonly) NSUInteger framesWritten;
@property (readonly) NSUInteger framesDropped;   // discarded because the encoder could not keep up
@property (readonly) NSSize outputSize;          // zero until the first frame
// Called on the main queue if writing fails; the recorder is then no longer recording.
@property (copy, nullable) void (^failureHandler)(NSError *error);
@end
```

Implementation notes: one serial queue owns the writer. `appendTexture:` asks the pacer (under a lock), drops if 3 frames are in flight, else dispatches to the queue: create the writer on the first frame (output size = settings, or source size where 0, each rounded down to even, min 2); pixel buffer from the adaptor's pool (BGRA, Metal compatible, IOSurface); `CVMetalTextureCache` texture; one render pass (clear black opaque, or transparent for ProRes 4444; aspect-fit quad; V flipped when `flipped`); `addCompletedHandler` → queue → append if `readyForMoreMediaData` else count dropped. A `dispatch_group` tracks frames in flight for `finish`. Writer: `movieFragmentInterval` 10 s, `expectsMediaDataInRealTime` YES, BT.709 colour properties, `AVVideoAverageBitRateKey` for H.264/HEVC (automatic: width × height × fps × 0.1, or × 0.06 for HEVC, fps 60 when uncapped). Timescale 60000.

```objc
@protocol RecorderSourceProvider <NSObject>   // implemented by the app delegate, main thread
- (NSArray<NSString *> *)sourceTitles;
- (nullable NSString *)selectedSourceTitle;
- (nullable NSString *)selectedSourceApplicationName;
- (void)selectSourceAtIndex:(NSInteger)index;   // -1 selects none
@end

@interface RecorderController : NSObject
- (instancetype)initWithDevice:(id<MTLDevice>)device sourceProvider:(id<RecorderSourceProvider>)provider;
// Settings: KVO-compliant, saved in user defaults
@property (nonatomic, copy) NSString *codec;
@property (nonatomic, assign) NSInteger width;
@property (nonatomic, assign) NSInteger height;
@property (nonatomic, assign) double fps;
@property (nonatomic, assign) double bitrate;
@property (nonatomic, copy) NSString *folder;
@property (nonatomic, copy) NSString *name;
// State: KVO-compliant, main thread
@property (readonly) NSString *state;            // "idle", "recording", "finishing"
@property (readonly, getter=isRecording) BOOL recording;
@property (readonly) NSTimeInterval elapsed;
@property (readonly) NSUInteger frames;
@property (readonly) NSUInteger dropped;
@property (readonly, copy) NSString *file;
@property (readonly, copy) NSString *error;
@property (readonly) NSInteger sourceWidth, sourceHeight;
@property (readonly) double sourceFPS;
@property (readonly) NSInteger oscPort, oscQueryPort;
- (void)startNetwork;                            // OSC receiver and OSCQuery server
- (BOOL)start;                                   // NO: see error
- (void)stopWithCompletionHandler:(nullable void (^)(void))handler;
- (void)toggle;
- (BOOL)selectSourceMatching:(NSString *)title;  // exact title, then case-insensitive substring; "" selects none
- (void)sourcesDidChange;                        // re-publishes /source's VALS
- (void)sourceSelectionDidChange;                // resets the source's measured size and rate
// Syphon's new-frame handler thread
- (void)frameReceived:(id<MTLTexture>)frame;
@end
```

The parameter table is an array of small objects (address, type tag, access, range, description, getter block, setter block); OSCQuery registration and OSC dispatch both iterate it. A 4 Hz timer updates `elapsed`, `frames`, `dropped`, `sourceFPS` while a window is open or a recording runs.
